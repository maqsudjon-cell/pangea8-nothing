Colophon

Из шрифта, одного акцента и build-скрипта.

tou.gg

Цвет. Страница — чернильно-синяя, почти чёрная. Бренд держит один акцент: сварочный оранжевый — для шва, точки в логотипе и главной кнопки, больше нигде. Голубой отмечает AI-работы, зелёный — языковые, а в списке работ у каждого продукта свой оттенок. Статус никогда не передаётся одним цветом.

Шрифт. Space Grotesk в крупных заголовках, Inter для чтения, JetBrains Mono для доменов, дат и подписей. Все три лежат рядом со страницей в woff2 — во время работы ничего не тянется из Google.

Знак. T, O, U вырезаны из геометрической сетки, для .gg — каретка терминала. Фавикон, touch-иконка и OG-локап 1200×630 генерируются скриптом scripts/brand.py из тех же woff2. Ни стоковых фото, ни нарисованных моделью людей.

Движение. Логотип печатает to you, роняет середину, сжимается в tou и опускает .gg — один раз за сессию, не при каждой перезагрузке. Всё остальное — появление при скролле, шов на ховере и счётчик. prefers-reduced-motion превращает это в мгновенные состояния, и ни один текст не ждёт JavaScript, чтобы стать читаемым.

Сборка. Обычный статический HTML, собранный build.mjs — без фреймворка, без рантайм-зависимостей, без build-сервера. Три языка — это три дерева URL и hreflang, а не подмена на клиенте. Хостинг GitHub Pages, DNS на Cloudflare.
