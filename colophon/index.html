Colophon

Made of type, one accent, and a build script.

Colour. The page is ink navy, almost black. One accent carries the brand: weld orange, used for the seam, the dot in the wordmark and the primary action — nowhere else. Cyan marks AI work, green marks language work, and every product carries its own hue in the work list. Status is never colour alone.

Type. JetBrains Mono carries the display sizes — the wordmark, every heading, every number — with Inter for reading and the same mono for domains, dates and labels. Both are self-hosted woff2 next to the page; nothing is fetched from Google at runtime. A proportional display face was tried and rolled back: the terminal voice is the brand.

The mark. T cut from a geometric grid, with the prompt caret beside it. Favicon, touch icon and the 1200×630 OG lockup are generated by scripts/brand.py from the same woff2 the site uses. No stock photos, no model-drawn people.

Motion. The wordmark types to you, drops the middle, closes up to tou and lands .gg — once per session, never on a reload. Everything else is scroll reveals, a hover seam and a count-up. prefers-reduced-motion turns all of it into instant states, and no text ever waits on JavaScript to become readable.

Build. Plain static HTML generated by build.mjs — no framework, no runtime dependency, no build server. Four languages are four URL trees with hreflang, not a client-side swap. Hosted on GitHub Pages, DNS on Cloudflare.
