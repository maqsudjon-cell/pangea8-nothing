代码与钢铁

车间就是工程学校。量尺寸、拼接、给焊缝加载测试。

车间很吵。钢材没有自动补全。你量开口，切割，点焊，检查直角，走满焊缝。然后把自己的体重挂上去 —— 不然就别把它送上五楼的阳台。

这就是完整的工程循环。软件假装这个循环可有可无，因为那边的故障是一个 500，而不是一根松开的栏杆。

白天我在塔什干焊接，夜里我为智能体写规格。方法是一样的：写接头、检查焊道、加载测试。智能体要是幻觉出一个不存在的库，那就是一处未熔合 —— 磨掉，重来。

大家把焊工当成一个剧情反转。它其实是学校。真正有用的文凭，是不交付自己不敢站上去的焊缝这个习惯。
