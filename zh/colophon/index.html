Colophon

由字体、一种强调色和一个构建脚本组成。

颜色。 页面是墨蓝色，近乎黑。整个品牌只靠一种强调色：焊接橙，用在焊缝、字标里的圆点和主要按钮上 —— 别处一律不用。青色标记 AI 相关的工作，绿色标记语言相关的工作，作品列表里每个产品还有自己的色相。状态从不只用颜色表示。

字体。 所有大字号都交给 JetBrains Mono —— 字标、每一个标题、每一个数字；正文用 Inter，域名、日期和标签仍用同一款等宽字。两者都以 woff2 放在页面旁边，运行时不会从 Google 拉取任何东西。一款比例字体试过之后又撤回了：终端的语气就是品牌本身。

标志。 T 从几何网格里切出来，旁边是终端的提示符。favicon、touch 图标和 1200×630 的 OG 图，都由 scripts/brand.py 用站点自己的 woff2 生成。没有图库照片，也没有模型画出来的人。

动效。 字标会把 to you, given gladly 打出来，让多余的字母掉下去，收拢成 tou，最后落下 .gg —— 每个会话只播一次，刷新不会重来。其余只是滚动时的出现、悬停时的焊缝和数字滚动。prefers-reduced-motion 会把这一切变成瞬时状态，而且没有任何一段文字需要等 JavaScript 才变得可读。

构建。 由 build.mjs 生成的纯静态 HTML —— 没有框架，没有运行时依赖，没有构建服务器。四种语言是四棵 URL 树加 hreflang，而不是浏览器里的切换。托管在 GitHub Pages，DNS 在 Cloudflare。
